# 🐍 30 Days Self-Learning Python Journey

**No mentor. No classroom. Just me, my laptop, and the determination to learn.** 💻

Welcome to my **30 Days Python Journey**! This repository documents my progress as I learn Python independently through self-study, daily coding practice, assignments, and hands-on problem-solving.

My goal isn't to master everything in 30 days. It's to build a strong foundation, stay consistent, learn from my mistakes, and become a better programmer every day.

## 🎯 Goals

- Learn Python fundamentals step by step.
- Practice coding regularly and solve problems independently.
- Strengthen logical thinking and problem-solving skills.
- Complete daily exercises and assignments.
- Build small projects using what I learn.
- Develop discipline and consistency as a self-taught learner.

## 📚 Learning Roadmap

Topics may evolve as I learn, but my journey will include:

- Variables and data types
- User input and type conversion
- Operators and expressions
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for`, `while`)
- Loop control (`break`, `continue`)
- Strings and common built-in methods
- Lists, tuples, sets, and dictionaries
- Functions
- Error handling and debugging
- Working with files
- Practice problems and mini-projects


## 💡 My Learning Approach

1. Learn a concept.
2. Write the code myself.
3. Test it with different inputs.
4. Find and fix mistakes.
5. Complete practice tasks.
6. Review what I learned and update my progress.

I am learning independently, so mistakes are part of the process. Instead of aiming for perfection, I want to understand the concepts and keep improving.

## 🚀 My Commitment

**30 days. Self-discipline. Daily progress.**

This repository is a record of my effort, challenges, lessons, and growth. I may struggle along the way, but I will keep learning one step at a time.

Thanks for visiting my journey! ⭐
