🎯 Project Requirements
একটি Personal Finance Manager তৈরি করবে, যেখানে ব্যবহারকারী নিজের আয়, খরচ ও সঞ্চয়ের হিসাব রাখতে পারবে।

Step 1 — User Profile

ব্যবহারকারীর Name, Age এবং Monthly Income ইনপুট নেবে। বয়স ও আয় Validate করবে। ভুল Data Type দিলে try-except দিয়ে Handle করবে।

Step 2 — Expense Tracker

ব্যবহারকারী একটি List-এ ৫টি খরচ যোগ করবে। প্রতিটি খরচের Category থাকবে (Food, Rent, Shopping ইত্যাদি)। Dictionary ব্যবহার করে Category ও Amount সংরক্ষণ করবে।

Step 3 — Finance Calculator

Function ব্যবহার করে হিসাব করবে:
- Total Expense
- Remaining Balance
- Average Expense
- Highest এবং Lowest Expense
Balance Negative হলে Warning দেখাবে। অন্যথায় Savings Status দেখাবে।



সব তথ্য finance.txt ফাইলে Save করবে। পরে File Read করে আগের Report দেখাবে। File না থাকলে try-except দিয়ে Error Handle করবে।
